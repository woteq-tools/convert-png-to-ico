How it works

  1. Your PNG is decoded in the browser using the Canvas API.
  2. The image is resampled to each selected size.
  3. A standard Windows .ico container is written with a 32-bit alpha channel for every size, then downloaded to your device.

Powered by a browser port of the png-to-ico library (MIT licensed), producing byte-identical output to the original Node.js tool.

Frequently asked questions

Which sizes should I include?

For a website favicon, 16, 32 and 48 pixels cover browser tabs, bookmarks and desktop shortcuts. Windows also looks for a 256 px icon in the large-icon view, so including 256 is a good idea.

Why does my image look blurry at small sizes?

That is normal downscaling. Try a different resampling method — nearest neighbour keeps pixel art crisp, while bicubic is smoother for photographs and logos.

Are my images uploaded anywhere?

No. The file is read with the browser's File API and converted locally. Nothing is sent over the network, and no copy of your image is stored on a server.

Can the .ico file hold transparency?

Yes. Every generated size is stored as 32-bit BGRA, so transparent PNG areas stay transparent in the icon.
